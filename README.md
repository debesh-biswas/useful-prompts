# Useful Prompts

Copy-paste-ready prompts for coding with AI. Every prompt works as-is in any LLM
(Claude, ChatGPT, Cursor, Copilot, …): copy it, fill in the `{{PLACEHOLDERS}}`, run it.

The collection grows over time, starting with web/app UI/UX and expanding to every
part of software development.

## How to use

1. Find a prompt in the index below.
2. Copy the block under **Prompt**.
3. Replace every `{{PLACEHOLDER}}` with your own content.
4. Paste into your AI tool of choice.
